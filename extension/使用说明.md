# 使用说明 — MD Convertor 浏览器插件

把当前网页抓成 Markdown，连图片一起存进浏览器下载目录。**不需要桌面端在运行，也不需要任何服务器。**

- 适用浏览器：Chrome、Edge 等 Chromium 内核浏览器
- 扩展版本：见同目录 `manifest.json` 的 `version`

---

## 1. 安装（加载已解压的扩展程序）

1. 把本 ZIP 解压，得到一个 `md-convertor-extension/` 文件夹（里面就是本说明和三个扩展文件）。
2. 打开浏览器，地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）。
3. 打开右上角的**开发者模式**开关。
4. 点**加载已解压的扩展程序**，选中第 1 步解压出来的 `md-convertor-extension/` 文件夹。
5. 工具栏出现 MD Convertor 图标；可点浏览器工具栏的拼图图标把它固定到显眼位置。

> 本插件是未上架商店的手动安装扩展，浏览器升级或重装后可能需要重新加载。

## 2. 点一下图标会发生什么

在你想保存的网页上**点一次工具栏图标**，插件会：

1. 读取当前这一页的正文，转成 Markdown；
2. 把正文里的图片下载下来；
3. 在**系统下载目录根**下写出一对同源命名的文件：

```
~/Downloads/
  文章标题.md           # # 标题 + 来源链接 + 转换时间，正文用相对路径引用图片
  文章标题.images/      # 图片，命名如 001-hero.png
```

抓不到的图片会保留原始 URL，并在其下一行加一条注释 `<!-- 图片未下载：https://… -->`（渲染时不可见）。

完成后图标上的角标给出结果：

| 角标 | 含义 |
| --- | --- |
| ✓ | 成功，提示里写明存出的 md 名与内嵌的图片张数 |
| ! | 部分图片没抓到，或整篇失败，鼠标悬停图标可看到简述 |

## 3. 权限与隐私

插件只申请三项权限，`manifest.json` 里可以逐项核对：

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 只在你点图标时，作用于**当前这个标签页**，不常驻、不后台读取 |
| `scripting` | 把你点图标的那一页的正文读出来 |
| `downloads` | 把 `.md` 与图片写进下载目录 |

**口径**：

- **不读 Cookie、不读登录态、不读浏览器历史**，也不绕过任何登录、付费墙或访问限制；
- **不上传任何内容**：没有 MD Convertor 服务器，页面内容、图片、URL 都不会离开这台机器；
- 没有**任何**常驻脚本（`manifest.json` 里没有 `content_scripts`、没有 `host_permissions`）：不点图标，插件什么也不做。

## 4. 已知限制

- **特权页面不可用**：`chrome://`、`edge://`、浏览器扩展商店页、新标签页等不允许扩展注入，点图标会提示失败。本地 `file://` 页面需在扩展详情里手动打开「允许访问文件网址」。
- **必须手动点**：没有自动转换，也没有后台批量抓取。
- **图片可能抓不到**：需要 Cookie、登录会话、临时签名或 `blob:` 地址的图片会失败，此时保留原 URL 并加注释，不会静默丢掉。
- **整篇图片全部失败时**，会留下一个空的 `<标题>.images/` 目录（浏览器先建目录再下载，中断只删半成品文件，删不掉空目录）。
- **同名直接覆盖**：再次导出同一标题会覆盖旧的 `.md` 与 `.images/`，不会生成 `文章标题 (1).md`，避免把同名文件对拆散。
- **正文太短的页面会被判为失败**：提取不到足够正文（如导航页、图片墙）时直接报错，不做整页兜底。
- **落盘位置只能是下载目录**（浏览器硬限制），不能用绝对路径写到别处。

## 5. 与桌面端「转换既有文档」的分工

插件只管**抓下来**；批量**加工**交给桌面端 MD Convertor 应用：

```
网页 → 插件：提取正文 → 转 Markdown → 写盘（标题.md + 标题.images/）
                                              ↓（可选）
              桌面端「转换既有文档」：选目录 → 勾选 → 内嵌图片 / 翻译 → 输出到另一目录
```

- 插件产出的 `.md` 用相对路径引用 `.images/` 里的图片，整个目录可以随意搬移；
- 桌面端「转换既有文档」会读取这些文件，把图片内联成 base64、或按需翻译，再写到输出目录——**只读插件产物，不改写它**；
- 谁去加工都行：插件交付的是一对能直接用的文件，桌面端不是它运行的前提。

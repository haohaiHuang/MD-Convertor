# Plan — 快速返回与链接清空（feat-016）

- 状态：已完成并通过真实窗口验收；2026-08-11 完整发布门禁及新 ZIP 已通过，尚未合并。

## 目标

- 在链接转换模式提供“一键清空链接”，减少再次转换前的手工删除。
- 在长结果页面提供固定的“返回顶部”入口，便于快速回到输入区开始下一次转换。

## 行为

- 链接模式在 URL 非空时显示“清空链接”；点击后清除 URL、相关校验状态和当前共享结果，不弹确认框。
- 转换期间“清空链接”保持可见但禁用；用户须先停止转换。
- 页面垂直滚动约 500px 后，在右下角显示“返回顶部”；点击后平滑滚动至页面顶部输入区。
- “返回顶部”不修改链接、富文本内容、转换结果或模式；桌面和窄屏都必须保持可见、可点击且不遮挡核心操作。

## 非目标

- 不恢复已取消的整体 UI/UX 重设计，不调整视觉体系或页面信息架构。
- 不改转换管线、Markdown 规则、API、版本号、发布脚本或历史产物。
- 本事项完成前不运行 live、不打包、不合并分支；是否发布由用户后续单独决定。

## 测试 seam

- 纯状态 seam：`clearLinkInput(state)` 清除链接与共享输出，保留富文本草稿；loading 时返回原状态。
- 页面 seam：Playwright 通过可访问名称操作“清空链接”和“返回顶部”，验证结果清理、loading 禁用、滚动阈值、内容保留与窄屏位置。

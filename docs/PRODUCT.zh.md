# Product Specification

[English](PRODUCT.md) | **简体中文**

## 用户与目标

MD-Convertor 面向希望归档网页内容的个人用户。桌面端是 Apple Silicon Mac 单机应用，提供三个入口：粘贴公开网页链接、把用户已经复制的网页富文本粘贴进应用，或处理一个存放既有 Markdown 文档的目录。前两个入口在本机生成可预览、复制和下载的 Markdown 单文件；第三个入口批量处理磁盘上已有的 `.md` 文件（含浏览器插件保存的文档）。另有一个独立的 Chromium 浏览器插件覆盖「就在浏览器里干活」的场景（见下文）。

## 核心流程

1. 应用打开时停在入口画面，提供两个入口：「粘贴URL/富文本转换」保持单篇文章流程，「转换既有文档」进入本地文档页；每个画面都有「← 返回」回到来处。
2. 用户选择“链接转换”或“富文本转换”。
2. 链接模式接受 HTTP/HTTPS 网页链接；应用只填入输入框并校验格式。用户点击“转换”或按 Enter 后才开始抓取，转换期间可停止并保留原链接。链接非空时可一键清空 URL、校验和旧结果，转换中该操作禁用。
3. 富文本模式只处理用户主动提供的剪贴板快照：同时读取 `text/html` 与 `text/plain`，文本区域显示纯文本。具有语义结构时按净化后的 HTML 转换，否则以剪贴板纯文本为权威内容。
4. 富文本内容被用户手工编辑后，已捕获的 HTML 立即丢弃并明确降级为纯文本；再次粘贴会整体替换当前内容，不合并多个片段。来源 URL 为可选输入，只影响来源头部和相对链接/图片解析。用户可一键清空 HTML、纯文本、来源 URL 和旧结果；转换中该操作禁用。
5. 链接模式必要时使用内置浏览器渲染动态页面；富文本模式不重新抓取来源网页。两种模式完成后都展示文件大小、正文字数、图片数量、警告和 Markdown 预览。
6. 用户点击“复制”获得原始 Markdown，或点击“下载”把 `.md` 文件保存到本机：设置里的开关开着时直接写进所配置的默认目录，并显示实际落盘路径；开关关着时仍走系统的保存对话框。直写被拒时会说明原因并降级为保存对话框，文件照样能拿到。复制成功后短暂显示“已复制”。页面滚动超过约 500px 后提供固定的“返回顶部”，平滑回到输入区且不清除当前内容或结果。

## 本地文档处理

1. 本地文档页扫描所配置的输入目录，列出其中 `.md` 文件的大小、修改时间和是否已处理。已处理的文档默认不勾选，未处理的默认勾选；顶栏「全选」只勾选尚未处理的行。
2. 「一键转换」为勾选文档内嵌其引用的图片（沿用链接模式的下载、校验与大小预算），把结果写进输出目录。每一行都报告自己的结果——完成、已处理跳过、或失败及原因；汇总行给出图片与结果计数以及实际写入的目录，旁边带「打开目录」按钮。
3. 源目录只读，任何内容都不会写回源目录；输入与输出选了同一个目录会被拒绝，并提供一键改写到 `processed` 子目录的选项。浏览器插件保存的 `<标题>.md` + `<标题>.images/` 也落在输出目录，插件存的文档走同一条管线。
4. 勾选翻译时批量处理与单篇文章同规则：只有被勾选行的文档文本会发送到所配置的端点，翻译失败保留原文。
5. 设置页有「输入」「输出」两张目录卡片，用同一个 macOS 目录选择器；「恢复默认」重置为系统「下载」文件夹。

## 输出规则

- 文档包含一级标题、UTC 转换时间和正文；链接模式包含原始来源，富文本模式仅在填写有效 `sourceUrl` 时包含来源行。
- JPEG、PNG、WebP、GIF、AVIF 图片以 Base64/Data URI 内嵌，不生成资源目录；SVG、BMP、TIFF 等格式保留替代文本。
- Mermaid 有源码时输出 fenced `mermaid` 代码块；链接页面或粘贴内容只有渲染结果时，在对应安全边界内栅格化为 PNG，并沿用图片数量与文件预算。应用预览不执行 Mermaid 源码。
- 普通代码块保留为 fenced code；网页使用一个 `pre` 包含多个并列 `code` 节点表达同一代码块时，会把全部代码行、换行、缩进、实体、嵌套文本和标点规范化为一个完整代码块。
- 文件名兼容 macOS，最长 80 个字符；同时保留跨平台安全规则，便于把文件复制到其他电脑。
- 最多处理 30 张图片，单张源图最多 8 MiB；超过 2 MiB 或最长边超过 2048px 时转为 WebP quality 82，需压缩的动图保留首帧。
- 最终文件硬上限为 20 MiB；超限时从最后一张图片开始降级为替代文本，优先保留全部正文。只有纯正文自身仍超限时才返回错误。
- “正文字数”取提取后、生成 Markdown 前的正文字符数；图片统计同时反映原图数、成功内嵌数和省略数。

## 富文本粘贴规则

- HTML 先经过 DOM 语义门控和独立净化；标题按 `title`、`og:title`、首个 `h1`、纯文本首行依次回退，仍无标题时显示“粘贴内容”。
- 只保留转换所需的 HTML 语义和 `data-src`/`data-lazy-src` 图片属性，不开放任意 `data-*`；`script`、样式、导航、按钮及主动内容不会进入输出。
- Mermaid 源码可保留为代码块；富文本只有 Mermaid SVG 时不执行主动内容，而是移除脚本、事件和外部资源后在本机转为 PNG。无法安全栅格化或只有 Canvas 时改为占位文本并显示警告。
- 粘贴图片使用 `data-src` → `data-lazy-src` → `src` 的 lazy-first 顺序。远程图片仍走公网目标校验和 SSRF 防护；合规 `data:` 图片会重新解码、校验和优化后再内嵌，不原样透传。
- 富文本模式请求体（JSON 开销在内）最多 5 MiB；前端按 UTF-8 字节数预检，服务端再按声明长度和实际流式读取双重校验。

## 第一阶段支持范围

- Apple Silicon（arm64）Mac。
- 接受公开 HTTP/HTTPS HTML 页面并尽力转换。
- 支持静态 HTML 与无需登录的 JavaScript 动态页面。
- 支持无需登录或人工验证即可公开访问的微信公众号文章；微信验证页和已删除文章会显示明确错误，不生成伪正文。
- 支持用户从自己有权访问的网页主动复制并粘贴 HTML/纯文本；该模式不读取登录态，不绕过登录、付费墙或验证码。
- 两种模式均不需要账号；链接模式转换或富文本模式重新嵌入远程 HTTP(S) 图片时需要联网，纯文本和 `data:` 图片可离线转换。
- 可选文档翻译，目标语种为 11 种预置语言（简体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语、阿拉伯语），也可手填 BCP-47 追加。翻译由用户自行配置的模型完成：本机已安装的 agent CLI，或用户添加的 OpenAI 兼容云端 Provider。不涉及 MD-Convertor 自有的模型、账号或订阅。
- 另有一个面向「就在浏览器里干活」场景的 Chromium（Chrome、Edge、Brave）浏览器插件，2026-09-24 通过人工验收，以「加载已解压的扩展程序」从 `extension/dist` 载入：在当前页面点一下工具栏图标，就把正文与图片存成 `<标题>.md` + `<标题>.images/`。它跑在你已经打开的页面里，不需要桌面端也不需要服务，需要登录会话的图片同样下得来。下载失败的图保留原 URL 并在下一行带 `<!-- 图片未下载：… -->` 说明；同一页重复导出是覆盖上一对文件。它不上架商店，也没有 popup 或设置页。
- 本地批量处理既有 Markdown 文档（见上文「本地文档处理」）：选定目录、核对清单后，一次运行完成多份 `.md` 的图片内嵌或翻译，逐份报告结果，且不向源目录写入任何内容。

## 非目标

- 第一阶段不提供 Intel Mac、Windows 或 Linux 安装包。
- 不提供公网服务、跨设备同步、账号、历史记录或自动更新。
- 不绕过登录、付费墙、验证码或网站访问限制；不会代替用户抓取受限页面，只处理用户主动复制的剪贴板内容。
- 不支持任意文件/网页正文的自动导入，也不支持 PDF 等非 HTML 资源。本地文档处理只接受用户显式选定目录中的 `.md` 文件。也不承诺所有网页达到相同提取质量。
- 不承诺重新获取登录态、临时签名、`blob:` 或需要 Cookie 的远程图片；此类图片会保留替代文本并给出警告。
- 不从网页 JavaScript bundle 逆向恢复 Mermaid 源码，也不把原始 SVG/Canvas 写入 Markdown；链接模式只接受本次受控 Chromium 生成并校验的栅格截图，粘贴模式只接受经独立白名单清洗后由本机生成并重新校验的 Mermaid PNG。

## 隐私

链接、剪贴板 HTML/纯文本、网页、图片和转换结果不上传到 MD-Convertor 服务，应用代码也不建立转换历史、数据库或分析记录。粘贴内容只在当前本地转换请求中使用，诊断日志不记录正文、HTML 或来源 URL；应用不读取浏览器 Cookie 或登录态。Electron 和内置浏览器会在本机创建运行缓存与浏览器配置文件，但不会被应用用来同步或恢复转换内容；关闭应用后当前结果消失，用户主动保存的 `.md` 文件除外。

翻译会改变网络边界：当用户勾选翻译勾选框且转换完成时，正文会发送到用户自行配置的端点——本机的 agent CLI，或用户配置的云端 Provider。勾选即表示同意这次发送。云端 Provider 的 API Key 通过 macOS 钥匙串加密保存，不会进入 `settings.json`、本地服务或日志。MD-Convertor 自身仍然不上传任何内容：不向任何 MD-Convertor 自有服务上传内容，不建立翻译历史或缓存，也不保存正文。

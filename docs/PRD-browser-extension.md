## 1. 背景与目标

在浏览器里读到一篇好文章时，希望一键把它变成 Markdown 存到本地。

难点在于**这篇东西可能只有你有权限看**：登录后才可见的正文、带会话签名才能取到的图片。而唯一持有这份会话的，是用户当前的浏览器。

因此这件事必须在浏览器里做：读当前页面的 DOM（不是登录凭据），把正文提取出来，连图片一起落到本地磁盘。

目标（用户价值）：

1. 一键把当前页变成 Markdown，不需要复制粘贴。
2. **图片一起带下来**，用的是当前浏览器本来就有的访问权限。
3. 内容不出本机：不读 Cookie、不上传、不绕过任何访问限制。

## 3. 待对齐（写 FSD 前必须确认）

1. **入口形态**：浏览器工具栏按钮、右键菜单、还是页面内浮层（或组合）。
2. **转换前是否要预览**：线路 §1 的早期设想提到「简单预览」，但那会让插件变重。是否保留。
3. **同名文件怎么办**（例如多次导出同一篇）：覆盖还是加后缀。
4. **标题净化规则**：标题里的 `/` `:` 等非法字符怎么替换。
5. **是否允许用户改文件名**，还是完全自动。
6. **图片全部抓不到时**，md 还写不写。

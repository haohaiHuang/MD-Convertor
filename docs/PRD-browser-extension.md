## 1. 背景与目标

在浏览器里读到一篇好文章时，希望一键把它变成 Markdown 存到本地。

难点在于**这篇东西可能只有你有权限看**：登录后才可见的正文、带会话签名才能取到的图片。而唯一持有这份会话的，是用户当前的浏览器。

因此这件事必须在浏览器里做：读当前页面的 DOM（不是登录凭据），把正文提取出来，连图片一起落到本地磁盘。

目标（用户价值）：

1. 一键把当前页变成 Markdown，不需要复制粘贴。
2. **图片一起带下来**，用的是当前浏览器本来就有的访问权限。
3. 内容不出本机：不读 Cookie、不上传、不绕过任何访问限制。

## 3. 已确认项（2026-09-24 逐条裁定）

| # | 问题 | 裁定 |
| --- | --- | --- |
| 1 | 入口形态 | **只做浏览器工具栏按钮**（`chrome.action.onClicked`）。不做右键菜单、不做页面内浮层、不做 popup |
| 2 | 转换前是否预览 | **不做预览** |
| 3 | 同名文件怎么办 | **覆盖**（`conflictAction: "overwrite"`），**不加时间戳**。理由：`uniquify` 会把 `标题 (1).md` 与 `标题.images/` 拆散，一次重复导出就让文件对失去配对 |
| 4 | 标题净化规则 | 照抄桌面端 `src/lib/markdown.ts:46`：`<>:"/\|?*` 与控制字符 → `-`；去首尾空白与点；折叠连续空白；中文保留；上限 80 字符；净化后为空或命中保留名时回退 `page-<短哈希>` |
| 5 | 是否允许用户改文件名 | **不允许**，全自动 |
| 6 | 图片全部抓不到时是否还写 md | **照写**。正文仍有价值；失败的图保留原 URL + 标记，角标给 `!` |

补充裁定（本轮一并定下）：

1. **不共享代码**：B 自带转换核心（`extension/src/convert/`），不改桌面端任何文件；「两端一致」降级为「规则一致 + 各自自证」（PLAN §4.4、FSD §3.8）。
2. **反馈形式**：`chrome.action.setBadgeText`（`…` / `✓` / `!`）+ `setTitle` 详情，4 秒后清空。不做系统通知、不做 popup。
3. **不做整页兜底**：Readability 挑不出正文就报失败（并说明原因），不把导航页脚当正文塞进去。

## 4. 产物形态（本产品的对外契约）

一次导出产生**一对**同源命名的文件，落在系统下载目录根：

```
~/Downloads/
  文章标题.md
  文章标题.images/
    001-hero.png
    002-diagram.webp
```

| 项 | 约定 |
| --- | --- |
| md 文件 | `<净化后的标题>.md`；头部三行：`# 标题` + `> 来源：[url](<url>)` + `> 转换时间：<ISO 8601>` |
| 图片目录 | `<净化后的标题>.images/`（与 md 名**同源派生**，永远成对） |
| 图片文件名 | `<三位序号>-<URL basename slug>.<扩展名>`；扩展名取 URL pathname（白名单外则不带，最终以浏览器实际写入的文件名为准） |
| 正文引用 | 相对路径 `![](文章标题.images/001-hero.png)` |
| 图片去重 | 同一次导出里相同 URL 只存一份，多处引用指向同一个文件 |
| `data:` 图片 | 原样留在 Markdown 里（它本来就是内嵌的），不落文件 |
| 抓不到的图片 | 保留原始 URL，并在**下一行**加独立 HTML 注释：`<!-- 图片未下载：<url> -->`（渲染不可见，也不污染正文句式） |
| 已存在同名 | 覆盖 |
| 落盘位置 | 只能是下载目录下的相对路径（浏览器硬限制） |

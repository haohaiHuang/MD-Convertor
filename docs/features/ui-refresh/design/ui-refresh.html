③ 字重收敛

现在三份 CSS 里散着 10 个不同的字重（400 / 500 / 560 / 680 / 700 / 720 / 730 / 750 / 760 / 780）， 它们都是「比 normal 粗一点」的手调值，叠起来就是页面偏重的来源。收敛成两个变量： --weight-body: 400（正文）与 --weight-ui: 400（界面）——两个 token 当前同值，拆开是为了留一个只影响正文的旋钮。 初版把正文压到 300（本机确实装了 Inter Light / PingFang SC Light，不是合成细体），但真机实测小字识别度不足，已回退到 400。

⑤ 已知取舍

对比度余量 --muted 在新背景上从 4.74:1 降到 4.64:1，仍在 AA 线以上但余量变小。真机复核判定不通过（备注文字在细体 + 抗锯齿下读不清），按预设方案往深调一档到 #565E6B = 6.26:1（卡片 6.54:1）。
首页标题变化最大 .title 从 780 直接到 400，是整页气质最明显的一处改动。如果觉得「不够细」，把 --weight-ui 改成 300 即可（一条变量，回退成本为零）。
Inter 不是仓库资产 本机装了 Inter 全家族，目标机没装时会回退到系统无衬线；300 在那台机器上由 PingFang SC Light 承接中文。要不要把 Inter 打进包里，是另一件事（单文件约 800KB）。
正文细体已回退 初版把正文压到 300，真机实测小字识别度不足，--weight-body 已回退到 400；要再试只改这一个变量（抗锯齿那行是第二个旋钮）。

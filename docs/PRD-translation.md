## 1. 背景与目标

MD-Convertor 现在只做「网页/富文本 → Markdown」。用户希望在同一流程里把得到的 Markdown 翻译成指定语言，且翻译能力由用户自己配置的模型提供（本地代理或云端 Provider），不依赖任何 MD-Convertor 自有服务。

目标（用户价值）：

1. 转换完成后可直接得到目标语言的 Markdown，无需把内容复制到别的工具。
2. 模型可配置、可切换，本地与云端分开管理，密钥不落明文盘。
3. 已经是目标语言的文档不被无意义地整篇重译，只补翻非目标语言部分。

## 3. 已确认的产品决定

以下为对齐结论，实施阶段不得重新讨论；如需变更必须回到 PRD 修订。

| 议题 | 结论 |
| --- | --- |
| 本地代理含义（Q1.1） | 调用本机已安装的 agent CLI（首批 `pi`、`claude`），非本地 HTTP 模型服务 |
| 云端协议（Q1.2） | 只支持 OpenAI 兼容（`GET {base}/models`、`POST {base}/chat/completions`） |
| Provider 数量（Q1.3） | **只保存一条云端配置**（用户 2026-09-18 改向：原有的多条并存 + active 选择取消）；契约里 `providers[] + activeProviderId` 保持不变，界面只读写其中当前生效的那条 |
| 密钥（Q1.4） | 只有一个来源：`safeStorage`（Keychain）加密项存于 `userData/secrets.json`（0600），保存即生效；不提供环境变量来源（原「进程 env → `.env` → safeStorage」三级顺序已废止） |
| 模型列表（Q1.5） | 需要「获取模型列表」，并允许手动添加 |
| 流式输出（Q1.6） | 不需要。翻译是后端能力，前端只需看到最终译文 |
| 目标语种（Q2.1） | 预置 11 种 + 可手填 BCP-47 追加 |
| 目标语种数量（Q2.2） | 单一 active |
| 语言判定（Q2.3） | 不做本地检测库；判定与翻译都由当前生效的同一个模型完成 |
| 默认开关语义（Q3.1） | 开关持久化；勾选框状态每次启动按开关重置 |
| 勾选框作用域（Q3.2） | 链接面板与粘贴面板共用 |
| 翻译触发（Q4.1） | 转换完成后自动开始翻译（可取消） |
| Tab 形态（Q4.2） | 渲染后的 Markdown 预览；复制/下载跟随当前 Tab；统计与警告保持全局 |
| 翻译失败（Q4.3） | 不阻断转换：保留原文结果，译文 Tab 内显示错误并可重试；未勾选则不显示 Tab |
| 译文文件名（Q4.4） | 加目标语言后缀，BCP-47 小写连写，如 `article-zh-hans.md` |
| 占比口径（Q5.1） | 只统计正文散文（排除代码块、行内代码、URL、图片、HTML 标签、我们生成的元信息行），按字符数占比 |
| 判定时机（Q5.2） | 转换完成、发起翻译之前 |
| 阈值（Q5.3） | ≥ 97% 视为无需翻译（不显示译文 Tab，仅提示一行）；≥ 70% 弹确认；< 70% 直接全文翻译 |
| 确认框（Q5.4） | 两选：`只翻译非目标语言部分` / `不翻译` |
| 确认后行为（Q5.5） | 段落级切分，仅非目标语言段落送模型，目标语言段落原样保留，保序保结构 |
| 混合区间（Q5.6） | 30%–70% 不弹窗，直接全文翻译（含 30% 以下） |
| 阈值误判（Q5.7） | 不做二次抽样，固定阈值 |
| 保真要求（Q6.1） | 代码块、行内代码、URL、图片地址、Mermaid 源码、表格结构必须与翻译前逐字节一致 |
| 切分策略（Q6.2） | 按块切分 → 分批发模型 → 回填重组（不整篇一次送模型） |
| 长度上限（Q6.3） | 待翻译正文字符数上限 200,000；与既有 MD 获取能力的上限互不影响（既有能力不存在字符截断，详见 FSD §7） |
| 并发与超时（Q6.4） | 同一时刻只允许一个翻译任务，可取消；单次模型调用 180s，任务总预算按批次数动态计算（每批 180s + 30s 固定余量，下限 120s）。单次上限按云端推理模型实测调高：一次小批量翻译要 38–60s 的推理 token，60s 会在读响应体途中就切断调用 |
| 端点安全（Q6.5） | 仅对用户手动配置的 Provider 地址放开 loopback/私网；禁止跟随重定向到其他主机、禁止非 http(s)、禁止云元数据地址 |
| UI 隐私提示（Q6.6） | **不做**额外 UI 提示；改由文档据实改写（§5） |
| 文档落位（Q7.1） | `docs/PRD-translation.md` + `docs/features/translation/`（FSD 总纲 + 每阶段一份 Spec/Plan/Task 一体的执行文档） |
| 双语镜像（Q7.2） | 本轮新增文档不做 `.zh.md` 镜像 |
| 版本与切分（Q7.3） | 版本升至 `0.3.0`；按阶段拆分为可独立新会话执行的 Spec |
| 元信息翻译 | H1 标题参与翻译；我们生成的「转换时间」行不参与翻译，原文保留 |
| 设置入口形态 | 同窗口内 `/settings`，不新增独立设置窗口，不新增 macOS「设置…」菜单项 |
| 目标语种清单 | 简体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语、阿拉伯语（共 11 种） |

## 4. 用户可见行为（逐条）

### 4.1 勾选与触发

1. 设置里「默认开启翻译」为开时，应用每次启动后链接面板与粘贴面板的翻译勾选框默认选中；用户可随时取消，取消状态只影响本次会话。
2. 勾选状态下提交转换：先完成原有转换，成功后自动开始翻译，结果区显示进度与「取消」。
3. 未勾选、或未配置可用的生效模型时，不发起翻译，结果区与现状一致（无 Tab）。

### 4.2 占比判定与确认

转换成功后按 R4 判定正文字数占比：

| 目标语言占比 | 行为 |
| --- | --- |
| ≥ 97% | 不翻译，不显示译文 Tab，结果区提示一行「正文已是<目标语言>，无需翻译」 |
| 70% – 97% | 弹确认框：`检测到正文约 N% 已是<目标语言>，是否只翻译其余部分？` → `只翻译非目标语言部分` / `不翻译` |
| < 70% | 不打扰，直接全文翻译（`scope = all`） |

选择「不翻译」后不显示译文 Tab，原文结果保留可用。

### 4.3 结果区

- 新增两个 Tab：「原文」「译文」；内容均为渲染后的 Markdown 预览。
- 「复制」「下载」作用于当前 Tab；译文 Tab 的下载文件名为 `<原文件名>-<目标语言>.md`（BCP-47 小写连写）。
- 文件大小/正文字数/图片数量统计与转换警告保持全局显示（不随 Tab 变化）。
- 翻译失败：译文 Tab 内显示错误原因与「重试」；原文 Tab 不受影响。

## 6. 非目标（本轮明确不做）

- 不做流式输出、不做会话/多轮对话、不做翻译历史或缓存。
- 不调用 macOS `Translation.framework`，不做任何系统翻译集成。
- 不引入本地语言检测依赖（判定交给模型）。
- 不支持 Anthropic / Gemini 原生协议；不支持本地 HTTP 模型服务（本轮「本地」= 本机 CLI）。
- 不支持多目标语言并行翻译；不支持翻译中的人工编辑。
- 不新增独立设置窗口与 macOS「设置…」菜单项。
- 新增规划文档不做英文镜像。
- 不改变既有抓取、提取、图片、Mermaid 能力与所有既有安全限制。

## 7. 风险与待验证项

| 风险 | 处理 |
| --- | --- |
| CLI 长 prompt 传递（`claude` 现状把消息放命令行参数，会撞 ARG_MAX） | S3 先用 `--help` / 实测探针验证 stdin 支持与限权参数；无 stdin 支持则降级为临时文件传递；探针结论写入 S3 TASKS |
| 模型输出不稳定（加解释、代码围栏、编号错位） | 严格 JSON 契约 + 单次重试 + 失败即整体报错（不留半成品），见 FSD §5 |
| 大文档耗时与成本 | 200,000 字符上限、分批（≤20 块或 ≤8,000 字符/批）、任务总超时按批次数动态计算（下限 120s）、可取消 |
| 密钥进入本地服务进程环境 | 本地单用户场景下接受；主进程注入，renderer 永不接触密钥，日志与错误信息禁止包含密钥与正文 |
| 翻译破坏 Markdown 结构 | 分段器跳过全部非散文内容；身份翻译回归要求逐字节一致（FSD §8），任何破坏即测试失败 |
| 占比判定误判 | 固定阈值（97% / 70%），实测有问题再迭代；判定结果可复算（前端只消费服务端返回的块级标签） |

## 附录 A：macOS 系统翻译能力调研结论（已排除）

- 公开 `Translation.framework` 存在两条路径：`.translationTask`（macOS 15+，必须有驻留的 SwiftUI 视图，可触发系统下载授权）与 `TranslationSession(installedSource:target:)`（macOS 26.0+，无 UI 场景，但不能请求下载）。
- 本机实测（macOS 26.7）：无 app bundle 的普通进程即可链接并调用（`canRequestDownloads == false`），未安装语言对抛 `notInstalled`；全量扫描 420 个语言对，本机已安装语言对为 0。
- 结论：接入系统翻译意味着抬高 macOS 版本下限、且首次必须由用户授权下载语言包，与「用户自配置模型」方向不一致，本轮作废。

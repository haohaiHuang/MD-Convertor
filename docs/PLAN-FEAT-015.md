# Plan — 一键清空富文本内容（feat-015）

- 状态：已完成并重新发布验证（2026-08-11）；源码、live、完整发布门禁、打包应用冒烟和真实窗口验收均通过。

## 目标

在“富文本转换”模式提供“清空”按钮，一次移除已捕获的 HTML、纯文本、来源 URL 和当前转换结果，方便直接粘贴下一份内容。

## 行为

- 仅富文本模式显示；存在内容、来源 URL 或结果时可用。
- 清空后恢复空内容状态，不保留上一份 HTML、文本、来源、提示、错误或结果。
- 转换中禁用；用户须先停止转换。
- 不弹确认框；链接模式行为不变。

## 非目标

- 不改整体 UI/UX、链接模式、转换管线、Markdown 规则、版本号或发布脚本。
- 功能开发阶段不打包、不运行 live、不合并分支；2026-08-11 用户另行授权重新发布验证，分支仍不合并。

- 页面 E2E：清空内容、来源和结果；再次粘贴无旧数据；转换中禁用。
